# Email API guide

A short field guide for developers: **what an email API is**, how it differs from SMTP, and how to evaluate providers.

This is **not** a fork of any vendor’s docs. Product facts for Notify (a minimal transactional email API) live at [notify.cx](https://notify.cx).
